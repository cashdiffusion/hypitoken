## Advisor 模式能用吗?

可以。网关给每个上游凭证维护完整的 Claude Code 会话身份,advisor、深度思考、子 agent、MCP 工具调用都跟官方 CLI 一致。

## 限流时会怎样?

代理层会自动在凭证池里跨凭证重试。如果触发了你自己令牌的 RPM 或并发上限,响应会是 `429`,响应头带 `Retry-After`。

## 我的数据存在哪里?

对话内容只在内存里穿过代理,不落盘日志。令牌元信息、用量统计、计费台账落 SQLite。

## 可以用我自己的 API Key 吗?

可以 —— 在管理员面板的 **Credentials** 标签页添加 API key 或 OAuth 凭证。池调度器会自动挑选最健康的凭证处理请求。

## 什么是粘性会话?

每个客户端令牌在 10 分钟活跃窗口内的请求都落到同一个上游凭证。这样可以跨多轮保持提示词缓存命中,并维持 advisor 的会话连续性。
