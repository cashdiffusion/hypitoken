## 创建步骤

### 1. 进入密钥页面

登录控制台，在左侧菜单点「密钥管理」，或直接访问 [api.novadiffusion.com/app/tokens](https://api.novadiffusion.com/app/tokens)。

### 2. 新建密钥

点「创建密钥」，填写名称（如「Claude Code 工作 Key」便于区分用途）。可选地设置**每月消费上限**（美元，每个自然月重置）。保存即可。

### 3. 复制密钥

创建完成后，密钥会显示在列表中，格式为 `sk-cpa-` 开头的一长串字符。点旁边的「复制」按钮一键复制完整密钥到剪贴板——**不要手动选择文本**，按钮复制能保证不带多余空格或换行。

> **请妥善保管密钥**：不要提交到 Git 或泄露给他人。如果不慎泄露，立即在控制台删除并重新创建。

## 为什么建议多个密钥

给不同项目 / 客户端建独立密钥便于：

- 区分用量统计；
- 出问题时只吊销受影响的那一个；
- 团队协作时按人 / 按项目分配。

> 并发数和 RPM 使用服务端默认值。如需自定义限额，请联系管理员。下一步：[账户充值](/docs/top-up)。
