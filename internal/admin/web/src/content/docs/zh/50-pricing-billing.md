## 计费规则

每笔成功请求都会按 Anthropic / OpenAI 响应中上报的官方 token 数计费。运维侧可配置分组倍率，公式如下：

```text
扣款 USD = 官方 USD × 分组倍率
```

默认倍率为 `1.0`，即与官方价格一致。

## 单令牌限额

每个 API 令牌都可以独立设置限额：

| 限额 | 含义 |
| --- | --- |
| 月消费上限（USD） | 每自然月重置，在 Token 创建对话框设置 |
| 日消费上限（USD） | 服务器侧字段，可由管理员配置 |
| 并发数 | 同时进行中的请求数，服务器默认值由管理员设定 |
| RPM | 每分钟请求数，服务器默认值由管理员设定 |

触发限额时，网关返回 `429`，响应头会带 `Retry-After`。

## 请求日志

每笔请求都会记录时间戳、模型、token 数、扣款、状态和延迟。**Logs** 页面会展示每笔扣款的完整公式拆分：input × 单价 + output × 单价 + cache R/W = 官方 USD × 倍率 = 实际扣款。

## 在不同系统查看账单

| 系统 | 操作 |
| --- | --- |
| macOS | 用浏览器打开 `/app/billing` 查看钱包流水，打开 `/app/logs` 查看逐笔请求扣费 |
| Windows | 同样通过浏览器访问 `/app/billing` 和 `/app/logs`；如果你在 PowerShell 中调试 CLI，请确认环境变量已在新终端会话中生效 |

计费逻辑在服务端执行，和你使用 macOS 还是 Windows 无关。系统差异只影响客户端安装和环境变量设置方式。
