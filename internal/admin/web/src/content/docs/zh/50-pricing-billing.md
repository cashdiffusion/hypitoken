## 计费规则

每笔成功请求都按响应里 Anthropic / OpenAI 官方上报的 token 数计费,运维侧可配置分组倍率,公式:

```text
扣款 USD = 官方 USD × 分组倍率
```

默认倍率 `1.0` —— 与官方价完全一致。

## 单令牌限额

每个 API 令牌都可以独立限额:

| 限额 | 含义 |
| --- | --- |
| 单令牌总消费上限 (USD) | 每自然月重置 (在 Token 创建对话框设置) |
| 并发数 | 同时进行中的请求数,服务器默认值由管理员设定 |
| RPM | 每分钟请求数,服务器默认值由管理员设定 |

触发限额时,网关返回 `429`,响应头带 `Retry-After`。

## 请求日志

每笔请求都会记录时间戳、模型、token 数、扣款、状态、延迟。**Logs** 页面可查每一笔的完整公式拆分 (input × 单价 + output × 单价 + cache R/W = 官方 USD × 倍率 = 实际扣款)。
