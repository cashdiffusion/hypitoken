## 计费模型

HypiToken **按 Token 实时计费**。每次请求结束后立即结算：

```text
本次扣费 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价
```

不同模型的单价不同（越强的模型越贵）。**缓存命中**的输入 Token 通常按更低的单价计算，多轮对话因此更省。

## 查看实时价格

各模型的最新单价以控制台的 [价格页面](https://api.novadiffusion.com/pricing) 为准——价格可能随上游调整，页面始终展示当前生效单价。

## 用量与账单

- 在控制台「钱包 / 账单」查看余额、充值记录与消费明细。
- 在「日志」查看每次请求的模型、Token 数与扣费。
- 想分项目统计，给每个项目建独立 [密钥](/docs/create-key)，用量分开计。

## 额度与限制

- **试用额度**：新用户注册赠送，可先体验。
- **每月上限**：创建密钥时可设每月消费上限（美元，每个自然月重置），防止意外超支。
- **并发 / RPM**：使用服务端默认值，如需自定义请联系管理员。

> 余额不足时 API 请求会返回 `402 Payment Required`。建议开启低余额提醒。
